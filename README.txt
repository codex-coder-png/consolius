CONSOLIUS V8 Chromebook Compatibility

Extract the ZIP before opening index.html.
The standalone file can be opened directly.

V8 adds resource watchdogs and recovery UI so blocked HTML/JS/ROM resources do not leave CONSOLIUS stuck on Loading forever. Drag-and-drop is supported as an alternate import path. The app cannot override Chromebook administrator/browser restrictions; when a resource is blocked it reports that instead of hanging.
